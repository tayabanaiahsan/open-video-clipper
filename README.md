# 🎬 Open Video Clipper

**Free, open-source video clipping and automation tool built with Python.**

Open Video Clipper is designed to help creators convert long videos into short vertical clips for YouTube Shorts, TikTok, and Instagram Reels.

## 🚀 Features

- Automatic video scene detection
- Vertical 9:16 video clipping
- Optional AI-powered subtitle generation using Whisper
- Local video processing without paid APIs
- Python-based command-line workflow
- Open-source and community-driven development

## 🛠️ Technologies

- Python
- FFmpeg
- OpenCV
- Whisper

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/tayabanaiahsan/open-video-clipper.git
```

Navigate to the project folder:

```bash
cd open-video-clipper/ai-video-clipper
```

Follow the installation instructions in the project's existing README.
