# Contributing

Thank you for considering a contribution!

1. Open an issue describing a bug or feature.
2. Fork the repository and create a feature branch.
3. Install development tools: `python -m pip install -e ".[dev]"`.
4. Run `pytest -q` and add tests for behavior changes.
5. Open a pull request describing your changes and how you tested them.

Be respectful and avoid uploading copyrighted source footage to the repository.
